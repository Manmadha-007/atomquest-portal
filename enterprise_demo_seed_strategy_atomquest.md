# Progress Quality Guidelines

Your dataset should intentionally contain:

| Category | Target Ratio |
|---|---|
| Strong progress | 40% |
| Moderate progress | 30% |
| Stalled progress | 15% |
| Overdue | 15% |

This produces believable operational conditions.

---

# Quarterly Update Quality

Avoid repetitive or generic updates.

---

## GOOD Example — Strong Progress

```txt
Completed authentication hardening rollout and reduced login latency by 31%. Infrastructure validation completed in staging. Production rollout scheduled next sprint.
```

---

## GOOD Example — Risk

```txt
SOC2 evidence collection delayed due to dependency on third-party audit exports. Timeline risk identified for compliance milestone.
```

---

## GOOD Example — Operational Issue

```txt
Migration progress blocked by incomplete API contract documentation from external billing provider.
```

---

## GOOD Example — AI Research

```txt
Completed benchmark evaluation pipeline for retrieval experiments. Current model performance improved from 83% to 89% on internal QA dataset.
```
